Here’s a **shorter, simplified, copy-friendly version** of the `this` keyword in JavaScript:

---

## **`this` Keyword in JavaScript (Simplified)**

**Definition:**
`this` refers to the current context — *the object that is using the function*.

---

### **1. Global Context**

* Outside any function, `this` = global object (`window` in browsers).

---

### **2. Regular Functions**

* When a function is called as a method → `this` = that object.
* When called alone →

  * In non-strict mode: `this` = global object
  * In strict mode: `this` = `undefined`

---

### **3. Arrow Functions**

* Arrow functions **do NOT get their own `this`**.
* They use `this` from the **parent scope**.

---

### **4. Event Handlers**

* In DOM event handlers, `this` = element that triggered the event.

---

### **5. Example**

```javascript
const obj = {
  name: "John",
  sayName() {
    console.log(this.name);
  }
};

obj.sayName();         // 'John' (this = obj)
const fn = obj.sayName;
fn();                  // this = global/undefined
```

---

### **6. Useful Methods**

* `call()`, `apply()`, `bind()` can manually set `this`.

---

### **Quick Reminder**

`this` depends on **HOW the function is called**, not where it's written.
